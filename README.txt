ERIC'S RECOMP — iPhone PWA

Included:
- Current 5-day program
- Weight + rep logging for every set
- Previous-workout performance under each exercise
- Automatic rest timer
- Progression prompts when every set reaches the top of the rep range
- Body-weight logging
- Workout history
- Offline support after first load
- Local-only storage
- Exportable JSON backup

To install on iPhone:
A PWA must be opened from a normal HTTPS website before iOS can add it as a standalone Home Screen app.
Upload this folder to a static host such as GitHub Pages, Netlify, Cloudflare Pages, or your own host.
Then on iPhone:
1. Open the hosted page in Safari.
2. Tap Share.
3. Tap Add to Home Screen.
4. Name it Eric Recomp.
5. Open it from the new icon.

Your logs live in Safari/iPhone local storage for that website. Export a backup before clearing Safari website data.
